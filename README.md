# 实验一：带键盘事件的计算器

## 1. 环境
- Qt Creator / Qt Widgets（项目使用 qmake，打开 `Lab1.pro`）
- C++17
- Git

## 2. 运行步骤
1. 解压 `Lab1_completed.zip`。
2. 打开 Qt Creator，选择“文件 → 打开文件或项目”，打开 `Lab1.pro`。
3. 选择本机已安装的 Qt Desktop Kit；实验要求版本为 Qt 6.9.2，压缩包原有构建目录曾使用 Qt 6.11.2，建议在 Qt Creator 中重新配置 Kit。
4. 点击“配置项目”，然后执行“构建 → 构建项目”。
5. 点击运行，检查窗口、状态栏和按钮响应。
6. 如构建失败，先确认 Qt Widgets 组件、编译器和 Kit 配置正确，不要直接复用其他电脑的 `build` 目录。

## 3. 操作说明
- 鼠标：数字、小数点、`+ - × ÷`、`=`、`⌫`、`CE`、`C`。
- 键盘：数字键、小键盘数字、`.`/`,`、`+ - * /`、`Enter`/`Return`/`=`、`Backspace`、`Delete`、`Esc`。
- `CE` 清除当前输入，保留待处理运算；`C` 清除全部状态。
- 额外支持正负号、百分比、倒数、平方和平方根按钮。
- 鼠标按钮与键盘输入最终都调用 `handleToken()`，复用相同业务逻辑。

## 4. 建议测试用例
| 编号 | 操作 | 预期结果 |
|---|---|---|
| 1 | `12 + 3 =` | 显示 15 |
| 2 | `5.2 × 2 =` | 显示 10.4 |
| 3 | `8 ÷ 0 =` | 状态栏提示除数不能为 0，不崩溃 |
| 4 | `1 . . 2` | 显示为 `1.2`，第二个小数点被忽略 |
| 5 | `2 + × 3 =` | 连续运算符时以后输入的运算符替换前一个，结果为 6 |
| 6 | 输入 `123`，按退格 | 显示 `12` |
| 7 | `9 + 2 =`，再输入 `4` | 新输入替换结果，显示 `4` |
| 8 | `7 + 5`，按 `CE`，输入 `2 =` | 清除第二操作数后继续运算，结果为 9 |
| 9 | `C` 后输入 `6 × 7 =` | 显示 42 |
| 10 | 用键盘输入 `9 / 3 Enter` | 显示 3 |
| 11 | 对 0 执行 `1/x` | 提示 0 不能求倒数 |
| 12 | 对负数执行平方根 | 提示不能进行实数平方根运算 |

注意：以上为设计预期，提交前需在本机实际构建和运行后，将真实测试结果、截图填入实验报告。
